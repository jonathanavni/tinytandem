# PLAN

The active-work document. `/start` reads it; `/wrapup` updates it. Two parts:

1. **Current State** — the lean, session-by-session narrative of what's in flight. Stale detail gets archived to `PLAN-archive.md` every `/wrapup`.
2. **Decisions Log** — the cumulative "X over Y because Z" record. Never archived.

## Decisions Log

> Append-only. Each entry: the decision, the alternative rejected, and why. This is what a future session (or a teammate's agent) reads to understand *why* the code is the way it is. Cross-model review findings that were absorbed, declined, or punted get recorded here too (see `docs/handoff-pattern.md` §6).

- **<YYYY-MM-DD>** — <decision> over <alternative> because <reason>.
